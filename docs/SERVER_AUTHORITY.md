# 서버 권한 경계

이 게임은 지금 **로컬 데모 모드**다. 모든 계산이 브라우저에서 일어난다.
사람들과 경쟁하는 순간 그 계산은 전부 조작 가능해진다.

이 문서는 **무엇을 서버로 옮겨야 하는가**와 **지금 코드의 어디를 고쳐야 하는가**를 적어둔 것이다.

---

## 1. 원칙

1. **클라이언트가 만든 결과 수치를 그대로 저장하지 않는다.**
   "완등했으니 500원 주세요"가 아니라, 서버가 무슨 일이 있었는지 보고 스스로 계산한다.
2. **시간은 서버가 정한다.** 기기 시간을 바꿔서 방치 보상을 부풀릴 수 없어야 한다.
3. **랭킹 점수는 서버가 다시 계산한다.** 클라이언트 점수는 "이렇게 계산됩니다" 안내용이다.
4. 코드에서 옮겨야 할 자리에는 `// SERVER-AUTHORITY` 주석이 붙어 있다.

---

## 2. 서버가 맡아야 할 것

| 대상 | 지금 (로컬) | 서버 모드에서 |
|---|---|---|
| **시간** | `game/clock.ts`의 `now()` = 기기 시간 | `select public.server_now()` |
| **방치(오프라인) 보상** | `game/progress.ts` `advanceSchedule()` | edge function이 같은 함수를 서버에서 실행 |
| **돈 지급** | `emit(money.earn)` 직후 `climber.money += n` | 서버가 이벤트를 보고 지급 |
| **장비 획득** | `equipment.ts` `addItem()` | 서버가 구매·보상 검증 후 지급 |
| **등반 결과** | `climb.ts` `resolveStep()` (클라이언트 RNG) | 서버 시드로 재계산하거나 결과를 검증 |
| **퀘스트 보상** | `quests.ts` `claimQuest()` | 서버가 목표 달성 여부를 이벤트로 재확인 |
| **랭킹 점수** | `ranking.ts` `myRankings()` | 서버가 같은 식으로 계산해 순위 매김 |
| **크루 기여도** | 없음 (로컬 미구현) | 서버 집계 |
| **시즌 보상** | 없음 | 서버가 시즌 시작·종료 판정 |
| **대회 결과** | `competition.ts` `runCompetition()` | 서버 재계산 |

## 3. 이벤트 스파인이 곧 서버 전환 지점

`src/game/events.ts`의 `GameEvent`가 **"무슨 일이 있었는가"**의 유일한 기록이다.
퀘스트·업적·도감·기록이 전부 이 이벤트만 보고 판정한다. 화면이 직접 "완료했다"고 제출하지 않는다.

서버 모드에서는 이 구조를 그대로 쓴다.

```
[클라이언트]  플레이 → GameEvent 스트림 생성 → 서버로 전송
[서버]        같은 emit() 로직으로 재계산 → 보상 확정 → 세이브 갱신
```

**이 설계 덕분에** 서버 전환 시 새로 만들 게 적다. 이벤트 처리기를 서버에서 한 번 더 돌리면 된다.
반대로, 화면에서 상태를 직접 고치는 코드를 새로 만들면 그만큼 서버에서 검증할 수 없는 구멍이 생긴다.

## 4. 데이터베이스

`supabase/migrations/0001_init.sql` 참조. 요점만:

- 모든 사용자 테이블에 RLS: `auth.uid() = user_id`
- `attempts`(등반 기록), `ranking_entries`(랭킹) 는 **insert 정책이 없다** —
  클라이언트가 직접 쓸 수 없고 `security definer` 함수를 통해서만 기록된다.
- `save_slots.state`는 jsonb 한 덩어리. 랭킹·검증에 필요한 값만 생성 컬럼으로 꺼내 인덱싱한다.

### 아직 만들지 않은 서버 함수

```sql
-- 등반 결과 재계산 후 기록
create function public.submit_attempt(...) security definer;

-- 오프라인 진행 서버 재계산
create function public.advance_schedule(...) security definer;

-- 랭킹 점수 재계산
create function public.recompute_ranking(season text) security definer;
```

**이 세 함수를 만들기 전에는 랭킹을 열지 마라.** 점수를 마음대로 만들 수 있다.

## 5. 지금 UI가 하는 정직한 표시

서버가 필요한 기능은 작동하는 척하지 않는다.

| 화면 | 표시 |
|---|---|
| 크루 | "🔌 서버 연결 후 사용 가능" · 미리보기 멤버는 **"가상 데이터"**라고 명시 · 가입/응원 버튼 비활성 |
| 랭킹 | 내 예상 점수만 표시 · 순위 자리는 "서버 연결 후" · 범위(친구/크루/주간)는 🔒 |
| 시즌 | 기간 구조만 표시 · "시작·종료 시각은 서버가 정한다"고 명시 |

가짜 순위나 가짜 경쟁자를 만들지 않는다.
