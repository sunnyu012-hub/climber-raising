# 월드 진행 — 부산에서 세계까지

## 1. 전체 흐름

```
캐릭터 생성 → 홈짐 선택
  → 주간 일정 편성 → 훈련·휴식·알바·교류
  → 돈·경험치·인맥 획득
  → 문제 도전과 완등 → 스킬·무브 숙련도 성장
  → 장비 구매·장착
  → 홈짐 친숙도와 NPC 관계 성장
  → 퀘스트와 업적 완료
  → 다른 지점 방문 → 부산 원정
  → [준비 중] 전국 → 해외 → 대회와 시즌 → 세계 제패
```

**지금 실제로 갈 수 있는 데까지**: 캐릭터 생성 → 부산 웨이브락 3지점 → 클리프사이드 원정 → 미니대회.
그 뒤는 조건만 보이는 골격이다.

---

## 2. 지역 계층

| 지역 | 단계 | 상태 | 해금 조건 |
|---|---|---|---|
| 부산 | 홈 | ✅ **실제 플레이** | 처음부터 |
| 경남 | 국내 | 🚧 골격 | 레벨 8 · 완등 12 · 부산 해금 |
| 서울·경기 | 국내 | 🚧 골격 | 레벨 15 · 명성 200 · 경남 해금 |
| 대구·경북 | 국내 | 🚧 골격 | 레벨 15 · 경남 해금 |
| 충청 / 전라 / 강원 / 제주 | 국내 | 🚧 골격 | 레벨 18~22 |
| 아시아 | 해외 | 🚧 골격 | 레벨 25 · 명성 800 · 서울 해금 |
| 유럽 / 북미 | 해외 | 🚧 골격 | 레벨 35 |
| 세계 대회 | 세계 | 🚧 골격 | 레벨 50 · 명성 5000 |

🚧 골격 = `unlock.comingSoon: true`. **조건을 다 채워도 열리지 않고 "콘텐츠 준비 중"으로 표시된다.**
실제로 열려면 그 지역 암장을 `content/gyms.ts`에 추가하고 `comingSoon`을 지운다.

> 실존 암장의 상표나 특징을 임의로 만들지 않는다. 웨이브락 밖 확장 암장은 전부 **가상 이름**을 쓴다.

## 3. 부산 암장

| 암장 | 방문 조건 | 교통비 | 비고 |
|---|---|---|---|
| 웨이브락 서면점 | 없음 | 15,000원 | 홈짐 후보 |
| 웨이브락 남천점 | 없음 | 15,000원 | 홈짐 후보 |
| 웨이브락 부산대점 | 없음 | 15,000원 | 홈짐 후보 |
| 클리프사이드 볼더 (가상) | **암장 3곳 방문 + 레벨 3** | 45,000원 | **원정** — 배지·명성 지급 |

웨이브락 3지점은 능력치·보상·문제가 **완전히 동일**하다. 다른 건 색과 분위기 문구, 고유 이벤트 1개씩뿐이다.
브랜드가 다른 암장(클리프사이드)으로 가는 건 **원정**으로 친다 — 몸이 축나고 기분이 좋아지며 배지가 남는다.

## 4. 해금 조건은 한 곳에서만 판정한다

지역·암장·상점·퀘스트·대회가 **전부 같은 함수**를 쓴다.

```ts
// src/game/unlock.ts
unlockBlocker(state, rule) // 통과하면 null, 막히면 사용자에게 보여줄 이유 한 줄
```

`UnlockRule`에 넣을 수 있는 조건:

| 필드 | 의미 |
|---|---|
| `level` | 캐릭터 레벨 |
| `money` | 보유 금액 |
| `clears` | 누적 완등 수 |
| `visitedGyms` | 방문한 암장 수 |
| `fame` | 명성 |
| `regions` | 먼저 해금해야 할 지역들 |
| `quests` | 먼저 끝내야 할 퀘스트들 |
| `npcFriendship` | NPC별 친밀도 |
| `comingSoon` | 콘텐츠 미완성 (조건 무시하고 잠금) |

**새 조건이 필요하면** `UnlockRule`에 필드를 하나 늘리고 `unlockBlocker()`에만 추가한다.
조건 판정을 다른 곳에 또 만들면 화면 표시와 실제 계산이 어긋난다.

## 5. 진행을 밀어주는 것들

### 명성 (fame)
원정·대회·업적으로 오른다. 상위 지역 해금 조건에 쓰인다.

### 친숙도
- **암장 친숙도**: 방문할 때마다 오른다. 지점 고유 이벤트가 뜨면 조금 더.
- **지역 친숙도**: 그 지역 암장에 갈수록 오른다.

지금은 표시용이다. 나중에 할인·특별 문제·NPC 등장에 연결할 수 있게 데이터만 쌓아둔다.

### 레벨 해금표

| 레벨 | 열리는 것 |
|---|---|
| 1 | 암벽화·초크백 슬롯 |
| 2 | 초크 슬롯 |
| 3 | 클리프사이드 원정 (+암장 3곳 방문) |
| 4 | 미니대회 (+완등 3) · 의류 상품 |
| 4 | 테이프 슬롯 |
| 6 | 의류 슬롯 · 테크니컬 암벽화 (+완등 5) |
| 9 | 액세서리 슬롯 |

슬롯 해금은 `content/equipment.ts`의 `SLOT_UNLOCK_LEVEL`,
지역·암장·상점 해금은 각 콘텐츠의 `unlock` 필드에 있다.

## 6. 대표 진행 시나리오

새 캐릭터로 부산 첫 원정까지 실제로 도달하는 경로다.

1. 캐릭터 생성 → 서면점 선택
2. 튜토리얼 퀘스트 `일단 붙어보기` 자동 시작
3. 등반 탭에서 아무 문제나 도전 → 퀘스트 완료 → 메뉴 → 퀘스트에서 보상 수령
4. `첫 완등` 퀘스트 → 완등하면 칭호 «첫 탑» 획득
5. 일정에 알바를 넣어 돈을 번다 (`암벽화 살 돈 모으기` 퀘스트)
6. 성장 → 장비 → 상점에서 입문용 암벽화 구매 → 착용 → **등반 성공률이 실제로 오른다**
7. 메뉴 → 지도에서 남천점·부산대점 이동 (교통비 각 15,000원)
8. 3지점 방문 → `웨이브락 세 지점 돌기` 퀘스트 완료 + 업적 + 클리프사이드 해금
9. 레벨 3 이상이면 클리프사이드 원정 → 배지·명성·기념 액세서리
10. 레벨 4 + 완등 3이면 메뉴 → 대회에서 미니대회 참가

각 단계가 다음 단계의 해금 조건이 되도록 엮여 있다.

---

## 7. 새 지역을 실제로 열려면

1. `content/regions.ts`에서 그 지역의 `unlock.comingSoon`을 지운다
2. `content/gyms.ts`에 그 지역 암장을 추가한다 (`regionId` 일치, **가상 이름**)
3. 그 암장 전용 문제를 넣고 싶으면 `content/problems.ts`에서 `gymId`를 암장 id로 지정
4. `npm run test` — 콘텐츠 검사가 끊어진 참조를 잡아준다
5. 이 문서의 표와 `docs/BALANCE.md`를 갱신한다

코드는 건드리지 않는다.
