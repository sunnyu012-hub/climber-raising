# 게임 기획서 — 《클라이머 키우기》

## 1. 콘셉트
부산의 초보 클라이머가 훈련·휴식·재활·알바·크루 활동·원정을 반복하며 성장해
전국을 제패하고 최종적으로 세계적인 클라이머가 되는 **모바일 방치형 육성 게임**.

- 시작 지역: 부산 / 시작 암장: 콘텐츠 데이터 `busan-wavelock` (표시명 "부산 웨이브락", 교체 가능)
- 조작: 턴제 선택뿐. 타이밍·연타·정밀 조작 없음.
- 핵심 감정: 캐릭터가 자란다 / 내 빌드가 결과를 바꾼다 / 예상 못한 귀여운 사건 / 다음이 궁금함

## 1-1. 캐릭터 생성 (온보딩)
신규 사용자는 홈 대신 **3단계 온보딩**을 먼저 만난다. 1~2분 안에 끝난다.

```
1 기본 정보 → 2 내 클라이머 → 3 시작 암장 → 최종 확인
```
- **1단계**: 닉네임(랜덤 기본 + 직접 수정 + 다른 이름) · 성별(여자/남자) · 나이(18~60, 기본 28)
- **2단계**: 나머지가 전부 랜덤으로 생성된다. 마음에 안 들면 무제한 다시 뽑기
  (성별·나이는 유지, 0.3초 안에 새 결과)
- **3단계**: 부산 웨이브락 서면점 / 남천점 / 부산대점 중 하나
- **최종 확인**: "○○의 클라이밍 생활" 요약 → `클라이밍 생활 시작!`

**랜덤 생성 항목** — 외형(피부·머리형태·머리색·상의·하의·암벽화·초크백) ·
체형 특성 · 키 · 주특기 · 성격 · 시작 능력치 · 시작 무브 숙련도 · 자기소개 · 첫 칭호

**공정성** (`docs/BALANCE.md` 1-1절)
- 모든 캐릭터의 시작 능력치 총합은 동일하다.
- 성별과 나이는 능력치에 **전혀** 영향을 주지 않는다. 외형 후보와 문구에만 쓴다.
- 성별 고정관념으로 팔레트를 나누지 않는다.
- 세 지점은 능력치·보상이 동일하다. 분위기와 색만 다르다.

**주특기 8종** — 유연성 천재 · 발쓰기 우등생 · 악력 부자 · 지치지 않는 팔 ·
베타 탐정 · 강철 멘탈 · 암장 친화력 · 이상하게 운이 좋음
→ 관련 능력치를 조금 높게 만들되 **총합은 그대로**(다른 능력치에서 옮겨온다).

**성격 8종** — 일단 해보는 편 · 안전한 베타 선호 · 실패할수록 불타오름 ·
사람들과 함께할 때 강함 · 혼자 프로젝트를 파는 편 · 장비를 꼼꼼히 챙김 ·
몸 상태를 잘 살핌 · 이상한 베타를 좋아함
→ 아주 작은 패시브 하나씩. 압도적인 성격은 없다.

기존 사용자는 온보딩을 다시 보지 않는다. 더보기 탭의 `캐릭터 기본 정보 설정`에서
성별·나이·소속 지점만 보완할 수 있고, `캐릭터 생성 화면 미리보기`로 다시 만들 수도 있다
(외형만 변경 / 전체 초기화 / 취소 중 선택).

## 2. 핵심 루프
```
주간 일정 편성 → (접속 안 해도) 실시간 진행 → 접속 시 오프라인 리포트 확인
   → 등반 탭에서 문제 직접 도전 → 동작마다 베타 선택 → 즉시 연출 + 판정
   → 완등/추락 → 경험치·숙련도·피로·관절 반영 + 현재 일정 시간 단축
   → 능력치·스킬 성장 → 더 어려운 문제 → 새 암장/지역 해금
```
직접 플레이는 자동 진행보다 약 1.45배 이득이지만, 오래 못 들어와도 일정은 계속 돌아간다.

## 3. 성장 구조
### 능력치 (8)
힘 · 기술 · 유연성 · 지구력 · 루트파인딩 · 멘탈 · 인맥 · 행운
- 능력치별 경험치를 따로 쌓고, 필요 경험치를 넘기면 1 상승 (필요량은 레벨과 함께 증가).
- 캐릭터 레벨은 총 경험치로 오르고, 레벨업마다 스킬 포인트 1을 준다.

### 상태 수치 (별도)
체력 · 전신 피로 · 손가락/어깨/무릎 관절 · 기분(의욕)
- 관절은 "건강도"(100=멀쩡)이며 5단계로 표시: 건강 → 주의 → 뻐근함 → 통증 → 부상

### 체형 특성 (리치)
성장 능력치가 아니라 **캐릭터 특성**. 생성 시 랜덤으로 정해진다.
능력치는 건드리지 않고 등반 판정에만 연결된다.
- **짧은 리치** (148~163cm): 먼 홀드(`far`) 불리, **압축·하이스텝(`compressed`) 보너스**,
  중간 홀드 발견 확률 증가. 스킬 "리치 보완 베타"로 먼 홀드 패널티를 크게 줄일 수 있다.
- **균형형** (160~174cm): 특별히 강하거나 약한 거리가 없다. 어떤 빌드로도 무난하다.
- **긴 리치** (172~187cm): 먼 홀드 유리, 압축 동작과 좁은 스타트 불리. 발 기술이 더 중요해진다.

키는 체형과 연동된 **표시값**이다. reach와 중복으로 성공률에 적용하지 않는다.

### 무브 숙련도 (9)
하이스텝 · 플래깅 · 힘으로 버티기 · 중간 홀드 경유 · 힐 훅 · 다이노 · 발 바꾸기 · 휴식 · 초크 사용
- 사용할수록 오르되 고단계일수록 상승 폭 감소(체감 곡선).
- 숙련도는 성공률↑, 체력 소모↓, 관절 부담↓에 실제로 반영된다.

### 스킬트리 (3계열)
- **테크니션**: 정밀한 발쓰기 / 하이스텝 숙련 / 플래깅 안정화 / 리치 보완 베타
- **파워**: 락오프 / 오버행 적응 / 다이노 자신감 / 펌핑 저항
- **웰니스**: 워밍업 습관 / 빠른 회복 / 관절 관리 / 부상 위험 감지
스킬 효과는 전부 판정·회복 로직에 데이터로 연결된다(장식용 스킬 없음).

## 4. 일정 시스템
월~일, 하루 1개 활동. 실제 시간이 지나면 하루씩 자동 소화된다.
- 훈련: 볼더링 훈련 / 근력 훈련 / 유연성 훈련 / 루트파인딩 공부
- 회복: 완전 휴식 / 손가락 재활
- 알바: 홀드 세척 / 탈거 보조 / 초보자 레슨 보조
- 소셜: 크루 교류

각 활동은 소요 시간·체력·피로·관절·능력치 경험치·돈·인맥·부상 위험·랜덤 사건을 가진다.
편성 화면은 추천 편성 3종(안전 성장 / 돈 집중 / 실력 집중)과 경고(휴식 부족·과훈련·관절)를 제공한다.

## 5. 등반
한 문제 = 3~5개 동작. 동작 = 상황 + 캐릭터 대사 + 베타 2~3개.
판정 요소: 능력치 · 무브 숙련도 · 베타-문제 궁합 · 체력/피로 · 관절 · 장비 · 스킬 · NPC 버프 · 행운 · 난이도.
결과 4단계: **대성공 / 성공 / 부분 실패(버티기) / 추락**.
행운의 영향은 일반 문제에서 ±10%p 내외로 제한(무모한 베타는 배수로 확대).
선택지에는 등급 표시(매우 유리/해볼 만함/위험/무모함/알 수 없음)를 우선 노출하고,
루트파인딩 스킬·세터 친밀도가 충족되면 정확한 %를 보여준다.

## 6. 부상과 회복
부상은 무작위 처벌이 아니라 **누적 선택의 결과**다.
연속 등반, 피로, 관절 상태, 워밍업, 선택한 무브, 무리한 난이도, 휴식 부족, 스킬이 반영된다.
- 통증 단계에서 반드시 경고를 띄운다.
- 부상 중에도 재활·휴식·루트파인딩 공부·가벼운 알바·NPC 교류는 가능하다(게임이 막히지 않는다).

## 7. 알바
- 홀드 세척: 적당한 돈, 기술 소폭↑, 손가락 부담 낮음
- 탈거 보조: 높은 돈, 힘·인맥↑, 체력/관절 부담↑, 세터 이벤트 확률
- 초보자 레슨 보조: 돈+인맥, 루트파인딩·멘탈 경험치, 기술/인맥 조건 필요
확장 예정: 루트 세팅 보조, 영상 촬영, 대회 스태프, 암벽화 수선, 콘텐츠 제작, 개인 레슨, 협찬, 프로 선수

## 8. NPC
- **암장 사장**: 암장 안내, 홀드 세척 알바, 튜토리얼. 친밀도↑ → 알바 수입 보너스
- **세터**: 탈거 알바, 문제 힌트. 친밀도↑ → 정확한 성공률 공개
- **고인물 클라이머**: 조언, 응원, 테크닉 스킬 해금. 가끔 틀린 베타를 알려주는 귀여운 사건
확장 예정: 원정 동행, 할인, 레슨, 장비, 고유 스킬

## 8-1. 부산 웨이브락 3지점
| 지점 | 게임 내 문구 |
|---|---|
| 서면점 | 도심 한가운데에서 시작하는 첫 클라이밍 생활! |
| 남천점 | 바다 가까운 동네에서 느긋하게 시작해볼까요? |
| 부산대점 | 활기찬 대학가에서 새로운 크루를 만나보세요! |

**세 지점은 능력치·보상이 완전히 동일하다.** 확인되지 않은 실제 시설 특성을 사실처럼 쓰지 않기 위해서다.
구분은 카드/벽 색과 분위기 문구뿐이고, 문제 5개도 세 지점 모두 같다.
지점별 벽 성향·전용 문제·NPC는 사용자 피드백을 받은 뒤 `Gym.homeBonus` 등 준비된 필드로 붙인다.

## 9. 원정 (확장)
부산 → 전국 암장 → 자연 암벽 → 아시아 → 세계. 지역·암장은 `src/content/gyms.ts`에 추가한다.
해금 조건은 돈 + 능력치 + 완등 기록.

## 10. 랭킹 (확장)
종합 성장 / 최고 난도 완등왕 / 초견왕 / 리치 극복왕 / 인맥왕 / 원정왕 / 알바왕 /
슬랩왕 / 다이노왕 / 철벽관절왕 / 급성장왕 / 창의 베타왕 / 크루 기여왕
범위: 전체 / 친구 / 크루 / 주간 시즌 / 누적. **점수 계산은 반드시 서버에서** 한다.

## 11. 장기 확장 방향
부산 지역 암장 → 전국 원정 → 자연 암벽 → 아시아·세계 원정 → 크루/친구 → 시즌 랭킹 →
NPC 관계 심화 → 장비/꾸미기 → 알바와 직업 → 스킬트리 확장 → 부상/재활 심화 →
지역 이벤트 → 문제 종류 확대 → 세계 제패 엔딩
